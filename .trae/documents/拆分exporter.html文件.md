# 改进 Warcraft 3 模型队伍颜色功能

## 问题分析

当前的队伍颜色实现是简单地将整个模型的材质颜色替换为所选的队伍颜色，导致整个模型通体都有颜色。这与 Warcraft 3 模型的实际实现不符。

## 正确的实现原理

1. **队伍颜色纹理标识**：Warcraft 3 模型使用 `ReplaceableId` 来标识需要应用队伍颜色的部分

   * `ReplaceableId = 1` 表示队伍颜色纹理 (TeamColor)

   * `ReplaceableId = 2` 表示队伍光晕纹理 (TeamGlow)

2. **队伍颜色应用**：

   * 只有使用队伍颜色纹理的部分才会应用队伍颜色

   * 着色器中使用 ORM 图的 Alpha 通道作为队伍颜色的混合因子

   * 只有 Alpha 值大于 0.1 的区域才会应用队伍颜色

## 改进计划

### 1. 识别队伍颜色纹理

* 修改模型解析逻辑，识别模型中哪些材质使用了队伍颜色纹理

* 检查材质的 `ReplaceableId` 属性，确定是否为队伍颜色纹理

### 2. 改进材质创建逻辑

* 对于使用队伍颜色纹理的材质，应用队伍颜色处理

* 对于其他材质，保持原始材质颜色

### 3. 实现队伍颜色混合

* 在材质中添加队伍颜色混合逻辑

* 使用 ORM 图的 Alpha 通道作为混合因子

* 只有 Alpha 值大于 0.1 的区域才应用队伍颜色

### 4. 测试功能

* 选择不同的 Warcraft 3 模型进行测试

* 验证队伍颜色是否只应用到标志位置

* 确保其他部分保持原始材质颜色

## 预期效果

* 转换后的 GLTF 模型应该只有标志位置（如背部）显示队伍颜色

* 其他部分应该保持原始材质颜色

* 用户可以通过队伍颜色选择器选择不同的队伍颜色，效果应该与 Warcraft 3 游戏中一致
