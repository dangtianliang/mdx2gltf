# 前端模型查看器实现方案

## 项目结构

创建一个新的客户端目录 `clients/model-viewer/`，包含以下文件：
- `index.html` - 主页面结构
- `index.js` - 核心逻辑
- `index.css` - 样式文件

## 核心功能

1. **模型列表生成**：
   - 扫描 `src/model` 目录，按种族分类生成模型列表
   - 每个模型项显示模型名称和预览图

2. **模型加载与显示**：
   - 点击模型列表项时，加载并显示对应的 MDX 模型
   - 使用现有的 ModelViewer 类进行渲染
   - 实现模型的基本控制（动画选择、缩放、旋转）

3. **路径解析**：
   - 实现路径解析器，正确加载模型及其依赖的纹理文件

4. **UI 设计**：
   - 左侧显示模型列表（可折叠分类）
   - 右侧显示模型查看器
   - 底部显示模型控制选项

## 技术实现

1. **模型列表生成**：
   - 使用 Node.js 的文件系统 API 扫描目录（构建时生成）
   - 或在前端使用静态配置文件定义模型路径

2. **模型加载**：
   - 复用现有的 ModelViewer 加载逻辑
   - 实现模型切换功能，卸载旧模型并加载新模型

3. **交互功能**：
   - 实现模型列表点击事件
   - 添加动画选择下拉菜单
   - 添加缩放和旋转控制

## 测试计划

1. **功能测试**：
   - 验证模型列表是否正确显示
   - 验证点击模型是否能正确加载和显示
   - 验证模型动画是否能正常播放

2. **性能测试**：
   - 测试模型加载速度
   - 测试多个模型切换的性能

3. **兼容性测试**：
   - 测试不同浏览器的兼容性
   - 测试不同设备的兼容性

## 实现步骤

1. 创建 `clients/model-viewer/` 目录结构
2. 实现 `index.html` 页面结构
3. 实现 `index.js` 核心逻辑
4. 实现 `index.css` 样式文件
5. 构建并启动项目
6. 进行功能测试和性能测试

## 预期效果

- 一个美观、易用的 War3 模型查看器
- 能够快速浏览和查看 src/model 目录下的所有模型
- 支持模型的基本控制和动画播放
- 响应式设计，适配不同屏幕尺寸
