# MDX到glTF转换工具开发计划

## 目标
创建一个完整的MDX到glTF转换工具，集成到左侧菜单中，允许用户选择模型并导出为通用3D格式。

## 开发步骤

### 1. 项目结构搭建
- 在 `clients/model-viewer` 目录下创建 `exporter.html` 页面
- 在左侧菜单中添加"导出"链接，指向新页面
- 安装必要的依赖库：war3-model 和 Three.js GLTFExporter

### 2. 页面布局实现
- 创建响应式布局，左侧为模型选择区域，右侧为转换和下载区域
- 添加模型上传和选择功能，支持从src/model目录选择模型
- 实现转换选项配置（如输出格式选择、纹理处理等）
- 添加进度显示和错误提示界面

### 3. 核心功能实现
- **MDX解析**：使用war3-model库解析MDX文件，提取几何体、骨骼和动画数据
- **Three.js转换**：将解析后的数据转换为Three.js场景对象
- **GLTF导出**：使用Three.js的GLTFExporter将数据导出为glTF/GLB格式
- **纹理处理**：支持BLP纹理的自动检测和处理
- **下载功能**：生成转换后的文件并提供下载链接

### 4. 错误处理和优化
- 添加详细的错误处理，捕获并显示转换过程中的错误
- 实现进度条，显示转换的各个阶段
- 优化大型模型的处理，避免浏览器崩溃
- 添加模型信息显示，如顶点数、面数、骨骼数等

### 5. 集成和测试
- 将新页面集成到现有导航结构中
- 测试各种类型的MDX模型转换
- 验证转换后的glTF文件可以在其他3D软件中正常打开
- 测试纹理处理和骨骼动画导出

## 技术要点

- **MDX解析**：使用war3-model库的parseMDX函数解析模型数据
- **Three.js转换**：将MDX数据映射到THREE.Mesh、THREE.Skeleton等对象
- **GLTF导出**：使用GLTFExporter的parse方法导出模型
- **文件处理**：使用FileReader API处理用户上传的文件
- **错误处理**：添加try-catch块和错误回调
- **性能优化**：使用Web Workers处理大型模型的解析

## 预期结果
创建一个功能完整的MDX到glTF转换工具，允许用户：
- 从列表中选择或上传MDX模型
- 配置导出选项（如GLTF/GLB格式）
- 查看模型信息和转换进度
- 下载转换后的3D模型文件
- 获得详细的错误提示和操作指导

## 测试计划
1. 测试不同类型的MDX模型转换
2. 验证转换后的glTF文件在Three.js和其他3D软件中的兼容性
3. 测试纹理处理功能
4. 测试大型模型的处理性能
5. 验证错误处理和用户反馈机制
