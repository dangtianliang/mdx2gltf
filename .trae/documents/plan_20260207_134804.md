# 实现导出功能 2期计划

## 项目分析

"/导出功能 2期.md"文件提供了一个完整的MDX到GLTF转换工具实现，解决了纹理丢失和动画丢失的问题。主要功能包括：

1. **BLP纹理自动解码** → PNG（嵌入GLTF或sidecar）
2. **多层材质**（Layer）合成
3. **骨骼动画烘焙**（Sequences → GLTF动画）

## 实现计划

### 1. 环境准备
- **安装依赖项**：安装three、@types/three、war3-model、pngjs等必要的依赖
- **创建项目结构**：创建src/convert目录用于存放转换工具

### 2. 核心功能实现

#### 2.1 创建mdx2gltf.ts文件
- **实现BLP转换工具**：blpToBase64函数，将BLP转换为Base64 Data URL
- **实现纹理路径解析**：resolveTexturePath函数，处理不同的纹理路径格式
- **实现Three.js材质创建**：createThreeMaterial函数，处理多层材质混合
- **实现骨骼动画烘焙**：bakeBoneAnimation函数，将MDX的序列转换为GLTF动画
- **实现骨骼层级创建**：createSkeletonHierarchy函数，创建Three.js骨骼层级
- **实现几何体创建**：createGeosetMesh函数，创建蒙皮网格
- **实现主转换函数**：convertMDX2GLTF函数，执行完整的转换流程

#### 2.2 创建命令行接口
- **实现CLI参数解析**：支持输入路径、输出路径、BLP基础目录、是否嵌入纹理、是否导出动画等选项
- **添加示例命令**：提供使用示例

### 3. 集成到现有项目
- **修改package.json**：添加依赖项和脚本
- **创建启动脚本**：创建start.js的扩展，支持转换功能
- **添加转换工具入口**：在模型查看器中添加转换工具的入口

### 4. 测试与调试
- **测试基本功能**：测试转换单个MDX模型
- **测试纹理处理**：测试BLP纹理转换和嵌入
- **测试动画处理**：测试骨骼动画烘焙
- **测试错误处理**：测试各种错误情况的处理
- **测试边界情况**：测试没有骨骼、没有纹理、没有动画的模型

### 5. 优化与改进
- **性能优化**：优化大型模型的转换性能
- **内存优化**：优化内存使用，避免内存泄漏
